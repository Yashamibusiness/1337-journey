# Ex03 — ft_print_numbers

## Subject

Create a function that displays all digits in ascending order, from `0` to `9`, on a single line.

* **Required file:** `ft_print_numbers.c`
* **Prototype:** `void ft_print_numbers(void);`
* **Allowed function:** `write`

## Approach

Begin with the character `'0'`. Use a loop to display each digit and move to the next one until `'9'` has been displayed.

## What I practiced

Character representation of digits, sequential iteration, and output with `write()`.
