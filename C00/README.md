# C00 — C Programming Basics

## Project Overview

C00 introduces the fundamentals of C programming through functions that display characters, numbers, and combinations.

The exercises focus on using `write()`, working with character and integer values, controlling program flow, and generating combinations.

## Exercises

| Exercise                 | Subject                   | Main concept                     |
| ------------------------ | ------------------------- | -------------------------------- |
| [Ex00](./ex00/README.md) | ft_putchar                | Character output                 |
| [Ex01](./ex01/README.md) | ft_print_alphabet         | Loops and characters             |
| [Ex02](./ex02/README.md) | ft_print_reverse_alphabet | Reverse iteration                |
| [Ex03](./ex03/README.md) | ft_print_numbers          | Digit output                     |
| [Ex04](./ex04/README.md) | ft_is_negative            | Conditional statements           |
| [Ex05](./ex05/README.md) | ft_print_comb             | Nested loops and combinations    |
| [Ex06](./ex06/README.md) | ft_print_comb2            | Integer-to-character conversion  |
| [Ex07](./ex07/README.md) | ft_putnbr                 | Integer handling and recursion   |
| [Ex08](./ex08/README.md) | ft_print_combn            | Recursive combination generation |

## What I learned

C00 helped me practice writing functions, using loops and conditions, handling characters and integers, and generating combinations with increasing complexity.

I also practiced compiling, debugging, checking Norminette, and documenting my progress.
