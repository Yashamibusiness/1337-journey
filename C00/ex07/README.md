# Ex07 — ft_putnbr

## Subject

Create a function that displays the integer passed as a parameter. It must be able to display every possible value of an `int`.

* **Required file:** `ft_putnbr.c`
* **Prototype:** `void ft_putnbr(int nb);`
* **Allowed function:** `write`

## Approach

Handle negative numbers and display the minus sign when needed. Extract and display the digits in the correct order, using recursion or another suitable approach.

Pay special attention to the minimum integer value, which cannot be safely negated using a standard `int`.

## What I practiced

Integer boundaries, negative numbers, digit extraction, and recursion.
