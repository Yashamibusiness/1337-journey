# Ex00 — ft_putchar

## Subject

Create a function that displays the character passed as a parameter.

* **Required file:** `ft_putchar.c`
* **Prototype:** `void ft_putchar(char c);`
* **Allowed function:** `write`

## Approach

Use `write()` to send the character to standard output. The function receives a character and its address is passed to `write()` so that one byte is displayed.

## What I practiced

Character parameters, function prototypes, and basic output using `write()`.
