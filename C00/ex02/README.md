# Ex02 — ft_print_reverse_alphabet

## Subject

Create a function that displays the lowercase alphabet in descending order, starting from `z` and ending at `a`, on a single line.

* **Required file:** `ft_print_reverse_alphabet.c`
* **Prototype:** `void ft_print_reverse_alphabet(void);`
* **Allowed function:** `write`

## Approach

Start from `z` and use a loop that moves backward through the alphabet. Display each character until `a` has been reached.

## What I practiced

Reverse iteration, decrementing character values, and controlling loop termination.
