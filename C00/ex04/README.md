# Ex04 — ft_is_negative

## Subject

Create a function that displays `N` if the integer passed as a parameter is negative, or `P` if it is positive or zero.

* **Required file:** `ft_is_negative.c`
* **Prototype:** `void ft_is_negative(int n);`
* **Allowed function:** `write`

## Approach

Use a conditional statement to check the value of the integer. Display `N` for negative values and `P` for zero or positive values.

## What I practiced

Integer parameters, comparison operators, and conditional statements.
