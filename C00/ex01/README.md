# Ex01 — ft_print_alphabet

## Subject

Create a function that displays the lowercase alphabet in ascending order, from `a` to `z`, on a single line.

* **Required file:** `ft_print_alphabet.c`
* **Prototype:** `void ft_print_alphabet(void);`
* **Allowed function:** `write`

## Approach

Start with the character `a` and use a loop to display each character in sequence. Continue until `z` has been displayed.

## What I practiced

Character iteration, loop conditions, and displaying a sequence of characters.
