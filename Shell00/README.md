# Shell00

Shell00 is the first Shell module of the 1337 Piscine.

It introduces the basics of working with the Unix/Linux command line, including files, directories, permissions, links, timestamps, Git, and other useful commands.

## Exercises

| Exercise        | Topic                                  |
| --------------- | -------------------------------------- |
| [Ex00](./ex00/) | Creating a file                        |
| [Ex01](./ex01/) | File properties & archive              |
| [Ex02](./ex02/) | Files, links, permissions & timestamps |
| [Ex03](./ex03/) | SSH public key                         |
| [Ex04](./ex04/) | `ls` & sorting                         |
| [Ex05](./ex05/) | Git commits                            |
| [Ex06](./ex06/) | `.gitignore` & Git                     |
| [Ex07](./ex07/) | `diff`                                 |
| [Ex08](./ex08/) | `find` & file cleanup                  |
| [Ex09](./ex09/) | `file` & magic files                   |

## Goal

The goal of this module was to become more comfortable with the terminal and understand the basic commands used to work with files, directories, permissions, links, timestamps, and Git.

Each exercise contains my solution, where applicable, notes explaining how I approached it and what I learned.
